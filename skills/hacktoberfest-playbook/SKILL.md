# Hacktoberfest Playbook (How to Win)

## 1. Writing wins, not code
- Rubric weight: Writing Quality >> everything. Budget ~50% of week on post.
- Structure: hook (person outside) → problem → why-open (offline/privacy/cost/swap) → architecture (Mermaid) → build log → field test with photos → what failed → how to run → credits.
- Show, don't claim: screenshots, GIF, 60-sec video, offline photo, real output logs.
- Minimum viable win: working demo + great story beats brilliant code + thin post.

## 2. Nail prompt + theme literally
- Every week = same core (open-source AI at core) + new theme (Wk1: Touch Grass = get people off-screen/outside; screen = shortest part).
- Repeat theme words back; judges score Relevance. End post with 1 paragraph mapping each theme phrase to a feature.
- Bonus points stated on page (e.g. Wk1: take it outside, use it, tell how it went) = do it, with evidence.

## 3. Make the open story undeniable
- Dedicate a section: model name + license, harness + customization, local vs cloud, cost ($0), data flow (stays on device), swap test (ran 2 models).
- One-line proof per claim: `ollama run` screenshot offline, network-off test, fine-tune/param change diff.

## 4. Play the odds: target a partner category
- Category winners drawn from smaller pool → meaningfully higher odds. Always ship a real integration for ≥1 (e.g. deploy on Render for Best Use of Render).
- Don't bolt on 5 partners thinly; one deep > five logos. Name category explicitly in post.

## 5. Ship testable in week
- Live URL (Render free tier) + GitHub public + README (setup <5 min, env example) + LICENSE + seed data + test creds.
- Scope for 5-6 days build + 1-2 days writing. Cut to: 1 user, 1 flow, 1 model, 1 deploy.

## 6. Reactions = tie-break + signal
- Tie-break is positive reactions. Publish early in window, share, reply to every comment, post field-test update.
- English required for prizes. List teammates' DEV handles. Use required tags.

## 7. Field-test loop (Wk1 example)
Ideas: offline bird-call ID (trail, no signal), garden planner (frost dates), foliage run-club router. Take outside → photo → quote result → log failure honestly.

## 8. Pre-submit checklist
- [ ] Open model/harness/local named + why-open section
- [ ] Theme words mapped, bonus attempted
- [ ] Live demo + repo + LICENSE + README
- [ ] Mermaid arch + screenshots/video
- [ ] Partner category integration + named
- [ ] Credits for reused code, AI disclosed
- [ ] Required tags, English, in-window publish
