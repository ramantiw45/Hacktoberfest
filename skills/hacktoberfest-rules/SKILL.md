# Hacktoberfest Rules (DEV Open-Source AI Challenge 2026)

> Source: https://dev.to/challenges/hacktoberfest-week1-2026-10-05, https://dev.to/challenges, https://hacktoberfest.com, DevRelay knowledge `hacktoberfest` + `dev-challenges` (verified 2026-09-30). Challenge page wins on conflict.

## What changed in 2026
- **No PR counting.** PRs/MRs earn zero rewards. No repo hunting, no `hacktoberfest-accepted` label.
- Build a **brand-new project with open-source AI at its core** + write about it on DEV.
- Organized by **MLH + DEV**, presented by **DigitalOcean**. Theme: *AI belongs to everyone*.
- Swag = **virtual stickers** (Fests, livestreams, DEV Challenges, GHW, tools). 3 stickers = sticker pack mailed (8-12 weeks after fest).

## Core build requirement (all weeks)
Must use open-source AI as **what makes it work** — at least one of:
1. Running an **open-weight model** (Llama, Mistral, Qwen, Gemma, etc.)
2. Building on **open-source agent harness/framework** (LangChain, CrewAI, AutoGen, OpenClaw, etc.)
3. Running **inference locally** (Ollama, llama.cpp, vLLM, Transformers)
- Post must explain **why open innovation matters**: offline use, data privacy, fine-tune/swap models, zero cost, hackable agent behavior, beats closed alternative where?

## Eligibility
- 18+ (or age of majority), DEV Member in good standing, email+internet access.
- Excluded jurisdictions per Official Rules — check https://dev.to/page/official-hackathon-rules + challenge page.
- Teams up to 4 allowed; list every teammate DEV handle or they get no badge/prize.
- One submission per person per challenge (default); must be **new work** started in window. Prior OSS credited.
- English required for prizes (non-English = completion badge only).
- AI tools allowed. Plagiarism = DQ (incidental) or DEV suspension (egregious).

## Judging (DEV = writing matters most)
1. **Writing Quality (weighted most heavily)** — a great build + thin post will NOT win.
2. Relevance to Prompt + Theme
3. Creativity
4. Technical Execution
5. Use of Partner Technology (only for partner categories)
- Tie-break: most positive reactions on DEV post.
- Must publish DEV post **within contest period** with required tags (see submission skill).

## Prizes per week
- Overall: **$250 USD + DEV++ membership + winner badge**.
- Each partner category: **$200 USD** (smaller pool = better odds — always target one).
- Badges (usually award day of announcement): completion for all valid, winner for winners.
- Payout: DEV emails within 10 business days; return affidavit + tax forms (W-9 etc.) within 7 business days or forfeit. Cash arrives 2-4 weeks after paperwork. Winner pays taxes.
- Free partner credits: Tinker, Render, Backboard, ElevenLabs at https://hacktoberfest.com/my/promos — claim first.
