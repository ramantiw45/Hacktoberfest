# Hacktoberfest FAQ

## Program
- **Do PRs count?** No. 2026 killed PR counting. Build + write instead. You may still contribute to OSS for fun, it just earns nothing.
- **How do I join?** Sign in at hacktoberfest.com with MyMLH (free). Connect DEV account (recommended: badge + challenge credit). Register per-Fest for in-person.
- **How do I earn swag?** Collect virtual stickers (Fests, livestreams w/ on-screen code, DEV Challenges = 1 each, GHW up to 5, tool tasks). 3 = sticker pack mailed. 10 + 15 unlock more tiers. Fests also have limited T-shirts.
- **Cost?** Free. Plus free credits: Tinker, Render, Backboard, ElevenLabs at hacktoberfest.com/my/promos.
- **Missed a week?** Every challenge is a fresh start — you compete evenly.
- **Where are dates?** dev.to/challenges hub + each challenge page Key Dates. Week 1: Oct 05 → Oct 11 11:59pm PDT, winners week of Oct 12.

## Submissions
- **How do I enter?** Publish a DEV post in-window following the challenge Submission Template + required tags.
- **Can I use AI?** Yes, fully allowed if all other rules followed. Disclose via `ai_disclosure_level` (DevRelay defaults `some_ai`).
- **English required?** Only for prizes. Non-English still gets completion badge.
- **Teams?** Up to 4. List all DEV handles in post. All members must meet eligibility; prizes split/paperwork each.
- **Old work allowed?** No — build new in-window. Reused OSS must be credited + explain what's new. Keep commits in-window or note later commits in README.
- **Plagiarism?** Any non-generic prior work must be credited. Incidental = DQ; egregious = DEV suspension.
- **DevRelay session embed?** Optional but recommended: save agent session, embed `{% agent_session <id> %}` — helps judges see process.

## Judging & prizes
- **How judged?** Writing Quality (heaviest) > Relevance > Creativity > Technical Execution > Partner-tech use.
- **When winners?** Week after close, via DEV post.
- **Ties?** Most positive reactions wins.
- **Badges?** Participation + winner badges, usually same day as announcement.
- **Cash timeline?** Email within 10 biz days → return affidavit + tax docs within 7 biz days → paid in 2-4 weeks. Taxes on you.
- **Age/location?** 18+, some countries excluded — see Official Rules.

## Where to ask
- Challenge Launch Post comments, tag #hf26challenge. Check challenge FAQ + Official Rules first.
